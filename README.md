## 🚀 Privacy & Security Software Portfolio

Eleven open-source, zero-telemetry privacy tools built for local-first data protection:

1. **YFP (Your Files Protector)**: Free-space drive overwriter for Windows (`.exe`) and Android (`.apk`) that prevents file recovery by consumer forensic utilities.
2. **YFDW (Your File Downloader from Websites)**: Android download manager featuring 32-chunk parallel downloads, embedded Tor, and an automatic network kill switch.
3. **YPI (Your Privacy Indicator)**: Live iOS-style floating overlay for camera, mic, location, network, and Bluetooth usage on Android and Windows with encrypted logs.
4. **YTSR (Your TV Screen Recorder)**: Offline Android TV screen and audio recorder operating with zero `INTERNET` permissions.
5. **YPVM (Your Private Virtual Machine)**: Android Device Owner app providing a Host/Guest environment split with dual PINs and an explicit Emergency Unlock control.
6. **YSPB (Your Security & Privacy Browser)**: Sandboxed Next.js proxy browser featuring anti-fingerprinting, user-agent spoofing, media stream sniffing, and malware screening.
7. **Vault**: Single-user zero-knowledge storage vault with double client-side AES-GCM-256 encryption and SRP-6a authentication.
8. **YDC (Your Device Controller)**: LAN/Bluetooth hardware manager requiring explicit on-device confirmation for remote actions.
9. **Whistleblowing System**: Client-side encrypted anonymous complaint intake portal using RSA-OAEP and AES-256 with full infrastructure separation.
10. **YAMC (Personal File Scraper)**: Local Android folder watcher that archives incoming media and purges files according to user-configured retention timers.
11. **YPDC (Your Private Drive Cloud)**: Self-hosted, end-to-end encrypted distributed cloud storage utilizing master-password Argon2id and AES-256-GCM encryption.
